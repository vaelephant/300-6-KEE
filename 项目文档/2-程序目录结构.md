# KEE 程序目录结构

仓库是 Cargo workspace + 独立前端。根上「一个服务端二进制 + Postgres」，前端开发时由 Vite 代理 `/api`。

---

## 顶层一览

```text
300-6-utopia/
├── Cargo.toml / Cargo.lock     # Rust workspace
├── crates/                     # 后端各 crate
├── web/                        # 前端（Vite + React + TypeScript）
├── migrations/                 # Postgres 迁移（sqlx，只向前）
├── docs/                       # 设计与决策记录（英文）
├── 项目文档/                   # 中文项目说明（本目录）
├── scripts/                    # 基准与辅助脚本
├── docker/ · docker-compose*.yml
├── data/                       # 本地运行时数据（通常不入库）
│   ├── files/                  # 上传/同步的文件 blob
│   └── index/                  # Tantivy 全文索引目录
├── assets/                     # 仓库展示用静态资源
├── README.md · README.zh-CN.md
└── .env.example
```

本地开发常见命令：

| 步骤 | 命令 |
|---|---|
| 起库 | `docker compose up -d db` |
| 后端 | `cargo run -p utopia-server`（默认 :1516，启动跑迁移） |
| 前端 | `cd web && pnpm install && pnpm dev`（:5173） |

## `crates/` — Rust 包

| Crate | 职责 |
|---|---|
| **utopia-server** | HTTP API、任务编排、抽取/对齐/摄入/对话/MCP 等业务入口 |
| **utopia-store** | Postgres 访问：文档、图谱、本体、任务、审阅、物化…… |
| **utopia-core** | 共享模型、配置、错误类型、密钥封装 |
| **utopia-ingest** | 文件解析、版面/表格、分块、来源侧阅读 |
| **utopia-extract** | 开放抽取契约、对齐/蕴含提示与解析、时间说法、勘误协议 |
| **utopia-llm** | OpenAI 兼容客户端（流式、限流分类、用量） |
| **utopia-search** | Tantivy 全文索引读写 |
| **utopia-reason** | 本体公理 → 规则 → 前向链派生 |
| **utopia-cli** | 命令行工具入口 |

依赖方向大致为：

```text
utopia-server
  ├── utopia-store ← utopia-core
  ├── utopia-ingest / extract / llm / search / reason
  └── （API 层组装上述能力）
```

| `extraction.rs` · `extraction_open.rs` | 开放抽取任务 |

| `retrieval.rs` · `query_engine/` | 检索融合；挂载库问数（Postgres/MySQL/Trino/…） |

## `migrations/`

按序号递增的 SQL（如 `0001_core.sql`、`0003_graph.sql`、`0004_ontology.sql`…）。服务启动时由 sqlx 自动 migrate。**只向前滚**，升级前需备份数据库与 `data/`。

图谱相关早期迁移可对照：

- `0001_core` — 工作区、账号、LLM 设置等  
- `0002_ingest` — 文档与分块  
- `0003_graph` — 实体、事实、证据、双时态列  
- `0004_ontology` — 类与关系词表  
- `0005_resolution` — 消歧 / 合并  

后续编号覆盖开放陈述、绑定、蕴含、名字向量、勘误等演进（以文件注释与 `docs/decisions` 为准）。

## `scripts/` · `docker/`

- **scripts/**：评测与批跑（如 `scripts/bench/`），服务产品主路径，但是度量与回归入口。  
- **docker/** + compose：一键起 Postgres / 整应用镜像；构建变体见 `docker-compose.build.yml`。

## 按「改什么」找目录

| 你想改… | 优先看 |
|---|---|
| 抽取提示词 / JSON 契约 | `crates/utopia-extract/src/open.rs` |
| 抽取任务编排、落库 | `utopia-server/extraction_open.rs`、`utopia-store` |
| 事实时态读写 | `utopia-store/world_axis.rs`、`record_axis.rs`、`temporal.rs` |
| 本体 API / Pack | `utopia-server/ontology_*`、`utopia-store/ontology.rs` |
| 全文检索 | `utopia-search`、`data/index/` |
| LLM 超时 / max_tokens | `utopia-llm/src/lib.rs` |
| 图谱 UI | `web/src/pages/Graph.tsx` 等 |
| 表结构 | `migrations/` |
| 产品级设计理由 | `docs/decisions/`、`docs/design/` |

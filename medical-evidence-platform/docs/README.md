## 设计依据与原则

1. 业务需求以项目提供的《多模态知识工程平台》方案第 2.3 节（2.3.1—2.3.10）为主要依据。
2. 技术实现优先复用仓库现有 KEE Rust 引擎及 `medical-evidence-platform` 已有前后端、医疗证据和数据契约能力。
3. 不因规划文档中出现某项技术名称，就视为该技术已在仓库落地；所有复用能力须经过代码审查和集成验证。
4. 医学知识必须保留来源、版本、证据定位、适用范围、时间信息和治理状态。
5. 新旧知识冲突不得仅按发布时间自动覆盖；自动化结果须保留理由和人工复核路径。
6. 患者可识别数据不进入首期公开演示数据。
7. 文档中的性能数字、准确率、合规目标属于需求或待验证目标，不代表当前系统已经达到。
